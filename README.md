One line. One stapler. One lost department.

This entry writes a single museum placard for an ordinary office object —
a stapler — treated as an ancient artifact dug from a lost civilisation,
to `/output/entry.txt`:

> Stapler, c. 1998. Pressed steel. Ritual binding device; one squeeze sealed a document, and occasionally a career. Gift of the department that no longer exists.

## Run

```sh
python3 main.py
```
